## Review requirement

Before publishing any repository containing third-party source code, binaries or documentation:

1. Record the source and version.
2. Record the original license.
3. Confirm redistribution is permitted.
4. Add required copyright and attribution notices.
5. Remove material that cannot be redistributed.

This file must be updated whenever a third-party component is added.

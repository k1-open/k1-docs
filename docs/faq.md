# K1 常见问题

## K1 是完整开源硬件吗？

不是。K1 是开放开发平台，开放协议、SDK、App 示例、非显示驱动、原理图 PDF、结构 STEP 和开发文档，但不开放 PCB、Gerber、BOM、贴片资料、显示驱动、校准和量产固件。

## 我可以先下载资料再买硬件吗？

可以。资料访问和硬件购买完全解耦，不需要先购买、注册或审批。需要实物联调时再购买官方硬件。

## 我可以自己贴片生产 K1 然后销售吗？

不可以。购买官方硬件或下载资料都不授予 PCB 制造、贴片、批量生产、OEM/ODM、白标或商业出货权。

## 为什么显示驱动不开放？

显示驱动、面板初始化时序、Gamma/亮度/颜色校准和显示私有固件属于核心实现。公开的是 Display API，应用可以通过 API 使用显示能力，但不能获得或复制底层实现。

## 结构 STEP 包含 PCBA 吗？

不包含。公开 STEP 已移除 PCBA、FPC、电子元器件和传感器子树，只保留外壳、支架、镜片固定、铰链和结构连接件。

## 为什么资料放在百度网盘？

完整 SDK、工具链和打包资料体积很大，不适合全部放进 GitHub。GitHub 用于协议、源码浏览、Issue、Pull Request 和版本记录；网盘用于大文件下载。

## 代码可以直接量产吗？

不可以。当前是 Developer Preview：BSP、BLE 固件和 App 仍需构建验证和安全审查。App 示例中的第三方 API Key 在客户端可被反编译提取，生产环境必须改为服务端代理。

## 我可以开发配件吗？

可以进行结构适配、接口验证和非商业原型制作。批量制造、商业销售或复制 K1 硬件结构需要按 `LICENSE` 取得书面授权。

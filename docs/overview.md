# K1 System Overview

本文说明 K1 外挂式智能眼镜开放平台的系统组成、仓库关系和版本边界。具体硬件规格、接口参数和兼容矩阵以对应版本资料为准。

## 1. 平台定位

K1 是开放开发平台，不是完整开源硬件。

- 公开开发所需资料，支持应用开发、非显示驱动适配、结构设计和维修。
- 不公开 PCB、Gerber、BOM、显示驱动、生产校准和量产固件。
- 公开资料无需购买、注册或审批即可下载。
- 官方硬件按需购买，购买不授予制造和商业出货权。

## 2. 系统分层

K1 分为四个层次：

1. 硬件层：V851S 主控、显示、音频、传感器、触摸、电源和外部接口。
2. 系统层：U-Boot、Linux、设备树、非显示驱动、刷机和恢复。
3. 接口层：BLE GATT、Display API、Audio API、Input API、OTA 和诊断。
4. 应用层：Android App、字幕、提词、通知、导航和第三方应用。

## 3. 仓库关系

- `k1-docs`：平台说明、快速开始、刷机与兼容性文档。
- `k1-hardware`：原理图、接口、测试点和维修资料。
- `k1-mechanical`：外壳 STEP/STL、安装尺寸和配件结构。
- `k1-v851s-bsp`：板级 DTS、非显示驱动和构建配置。
- `k1-sdk`：Android SDK、模拟器和开发工具。
- `k1-protocol`：BLE GATT 和显示、音频、输入、OTA、诊断协议。
- `k1-apps`：Android App 和场景示例。

## 4. 版本原则

- 文档、SDK、协议和固件分别维护版本号。
- 每个 Release 必须列出兼容的硬件版本、SDK 版本和固件版本。
- 协议变更必须说明向后兼容范围和迁移方式。
- 破坏性变更不得在同一主版本内静默发布。

## 5. 当前状态

截至 2026-11-26，K1 已进入 Public Developer Preview。文档、硬件、结构、协议和许可证已基本整理；BSP、SDK、App 和固件仍需构建验证，遗留项见 `release-readiness.md`。

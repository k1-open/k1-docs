# K1 开放范围

本文定义 K1 开放开发平台的公开内容、受限内容和发布边界。

## 1. 已开放

- 产品规格、硬件设计方案公开版、整机测试标准
- 主板、副板、充电板和环境光 FPC 原理图 PDF
- 外部接口、测试点、维修和支持说明
- 纯结构 STEP 交换文件、安装尺寸和配件接口
- BLE GATT、Display、Audio、Input、OTA 和诊断协议
- BLE 控制器参考固件源码
- Android App 示例和场景代码
- Python 协议参考实现
- LVGL 界面素材
- 刷机、构建、下载和常见问题文档

## 2. 计划补充

- Android SDK、设备模拟器和完整 API 文档
- 音频、传感器、触摸、电源和输入等非显示 Linux 驱动源码
- 可重复的 BSP、固件和 App 构建记录
- 正式协议测试向量、互操作测试和兼容矩阵
- App 生产安全改造和服务端密钥代理

## 3. 内部保留

- PCB 源文件、Gerber、钻孔、阻抗和版图文件
- 完整 BOM、贴片坐标、钢网和装配工艺
- 生产测试、校准参数、治具和良率数据
- 完整量产固件和量产配置
- 显示驱动、面板初始化时序、Gamma/亮度/颜色校准
- 安全启动密钥、Flash 加密密钥、签名私钥和设备证书
- 客户数据、供应商报价、内部账号和测试密钥
- K1 商标、Logo、官方认证和官方售后承诺

## 4. 第三方内容

第三方代码、文档、二进制库和供应商 SDK 必须：

1. 记录来源和版本。
2. 保留原始版权和许可证。
3. 确认允许再分发。
4. 在 `THIRD_PARTY_NOTICES.md` 中登记。
5. 无法确认再分发权利时，保持内部使用。

## 5. 变更规则

- 新增公开内容必须经过许可证和敏感信息检查。
- 不得把内部量产配置复制到公开仓库。
- 公开仓库不得包含密钥、Token、客户数据、供应商报价或未授权芯片资料。
- 发现误提交时，应先撤销访问并清理历史，再重新发布。

## 6. 分发与显示封版

- 完整 K1 资料通过百度网盘分发，GitHub 负责源码、文档和版本记录。
- 网盘包可以包含封版后的显示实现，但不提供显示驱动、面板时序、Gamma/校准和显示私有固件源代码。
- 公开 Display API 用于应用和配件开发，封版实现不得被绕过、反编译或复制。
- 下载和使用说明见 [download.md](download.md)。

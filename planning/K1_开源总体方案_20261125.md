# K1 开源总体方案（当前版）

日期：2026-11-25

## 1. 目标

把 K1 做成可持续的开放开发平台：

- 开发者可以先获取资料、开发 App、协议工具和结构配件，再决定是否购买硬件。
- 官方通过整机和显示模组销售获得收入。
- 不开放可直接复制生产的 PCB、Gerber、BOM、贴片和装配资料。
- 不允许未经授权复制、贴片生产、OEM/ODM、白标或商业出货。

## 2. 开放内容

- 产品规格和硬件设计方案公开版
- 原理图 PDF、接口、测试点和维修说明
- 纯结构 STEP 和安装尺寸
- BLE GATT、Display、Audio、Input、OTA 和诊断协议
- BLE 控制器参考固件
- Android App 示例
- Python 协议参考实现和 LVGL 素材
- 快速开始、构建、刷机、兼容性和 FAQ 文档

## 3. 不开放内容

- PCB 源文件、Gerber、钻孔和阻抗
- 完整 BOM、贴片坐标、钢网、装配和生产工艺
- 显示驱动、面板时序、Gamma/亮度/颜色校准
- 显示私有固件和生产测试
- 安全启动密钥、签名私钥、设备证书
- 客户数据、供应商报价和内部账号
- 不属于 K1 的第三方芯片开发资料

## 4. 许可证

| 内容 | 许可证 |
|---|---|
| 文档、协议 | CC BY 4.0 |
| SDK、App、BLE 控制器 | Apache-2.0 |
| K1 原创 BSP 代码 | GPL-2.0-only |
| 硬件、结构交换文件 | K1 Hardware Development License 1.0 |

K1 商标、Logo、产品图片和官方认证不在许可证授权范围内。

## 5. 实施步骤

1. 完成公开内容和敏感信息审查。
2. 完成结构 STEP 纯结构化处理。
3. 完成产品规格和硬件设计方案脱敏。
4. 补齐许可证、README、构建、刷机、兼容和 FAQ。
5. 完成密钥扫描、第三方再分发权和分支保护。
6. 按阶段公开仓库并发布 `K1 Developer Preview v0.1`。

## 6. 公开顺序

1. `.github`、`k1-docs`、`k1-hardware`、`k1-mechanical`、`k1-protocol`
2. `k1-ble-controller`、`k1-v851s-bsp`
3. `k1-sdk`、`k1-apps`

公开前状态见 [release-readiness.md](../docs/release-readiness.md)。

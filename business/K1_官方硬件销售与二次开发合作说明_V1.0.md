# K1 官方硬件销售与二次开发合作说明

面向客户、开发者和合作伙伴 | V1.0 | 2026-11-16

## 文件目的

本文说明 K1 外挂式智能眼镜的商业合作模式：客户可以先获取公开文档、协议、SDK 和开发资料，再根据实际需要购买 K1 官方硬件进行二次开发、调试、验证和商业部署。开放开发资料不授予复制硬件、贴片生产或批量制造的权利。

## 1. 商业模式

K1 采用“官方硬件销售 + 开放开发接口 + 制造边界保留”的模式。客户购买的是 K1 官方硬件、相关配件以及可选的技术支持服务，不是 PCB、BOM、贴片工艺或整机制造授权。

| 层级 | 包含内容 | 客户获得方式 | 商业边界 |
|---|---|---|---|
| 开放开发层 | 产品规格、协议规范、SDK、App 示例、非显示驱动、原理图、结构 STEP、配件接口和开发文档 | 可直接从公开仓库获取，无需先购买硬件 | 按各仓库许可证用于开发和集成 |
| 官方产品层 | K1 整机、开发样机、配件、充电和数据接口相关产品 | 按报价单、订单或合作协议购买 | 官方硬件销售和相关服务收入 |
| 受限制造层 | PCB 源文件、Gerber、完整 BOM、制作单、贴片坐标、钢网、装配工艺、显示驱动、面板时序、Gamma/校准和生产测试资料 | 不随开放资料提供 | 复制、贴片生产和批量制造须另行获得书面授权 |

## 2. 客户可以先获取什么

- 无需先购买硬件，即可下载和阅读 K1 产品规格、开放范围、协议、SDK、App 示例、结构文件和开发说明。
- 可先评估软件功能、接口能力、结构尺寸和二次开发可行性，再决定是否采购官方硬件。
- 需要实物显示、音频、传感器、功耗、佩戴、射频、可靠性或整机联调时，购买 K1 官方硬件可以获得真实设备验证条件。
- 购买硬件不会改变公开资料的许可证，也不会自动获得硬件制造或批量出货权。

## 3. 开放开发范围

| 类别 | 开放内容 | 客户可以做什么 |
|---|---|---|
| 文档与规格 | 产品规格、系统概述、开放范围、快速开发、烧录和调试说明 | 用于选型、评估、开发和培训 |
| 协议与接口 | BLE GATT、Display API、Audio、Input、OTA、诊断和错误码 | 开发手机 App、上位机、配件和联调工具 |
| SDK 与示例 | Android SDK、设备模拟器、应用示例和 LVGL UI 示例 | 开发自有应用、界面和业务功能 |
| 驱动与板级配置 | 音频、传感器、触摸、电源、输入等非显示驱动和板级配置 | 适配外设、调整非受限驱动和开发配件 |
| 硬件开发资料 | 原理图 PDF、接口定义、测试点、维修说明和结构 3D 交换文件（STEP） | 进行系统集成、结构适配、配件设计和 3D 查看 |

结构部分仅提供 STEP 3D 交换文件，用于查看、装配验证、结构适配和打印准备。不提供 Creo、SolidWorks、UG/NX、CATIA 等原生 CAD 源文件、参数化特征树、草图、装配约束、设计表或其他可编辑建模源文件。

## 4. 客户二次开发范围

| 场景 | 允许方式 | 说明 |
|---|---|---|
| 应用开发 | 在官方硬件上安装和运行客户自行开发的 App 或服务 | 客户保留其应用和业务内容，需遵守 SDK、协议和第三方许可证 |
| 系统集成 | 通过 SDK、协议和接口接入客户现有平台 | 可申请技术支持和联调服务 |
| 配件开发 | 基于公开结构和配件接口制作样品并进行验证 | 商业销售前需确认接口兼容、质量和授权安排 |
| 驱动适配 | 修改公开范围内的非显示驱动或增加客户外设 | 不得复制或传播受限显示驱动和生产配置 |
| 整机部署 | 采购官方硬件并部署客户软件后交付给最终用户 | 批量交付和品牌展示方式需在订单或合作协议中约定 |

## 5. 需要单独商业授权的事项

- 复制或制造 K1 整机、主板、副板、FPC 或充电仓。
- 使用 PCB 源文件、Gerber、完整 BOM、贴片坐标、钢网或装配文件进行生产。
- 以 OEM、ODM、白标或自有品牌方式生产同类硬件。
- 转售、分销或随客户系统批量销售 K1 官方硬件。
- 使用 K1 商标、Logo、认证标识或宣称获得官方认证。
- 获取、复制或再分发显示驱动、面板时序、Gamma/亮度校准、生产测试和安全密钥。

硬件购买不等于制造授权。上述事项必须另行签署商业合作、分销、ODM/OEM 或知识产权授权协议。

## 6. 商业合作方式

| 合作方式 | 适用对象 | 交付内容 | 商务说明 |
|---|---|---|---|
| 开发样机采购 | 独立开发者、企业研发团队 | 官方硬件、基础配件和开发资料入口 | 价格、数量和交期以报价单为准 |
| 小批量采购 | 完成原型验证、准备试产的客户 | 官方硬件和约定范围内的配套服务 | 按订单执行，可另行确认质保和售后 |
| 批量采购与分销 | 系统集成商、渠道合作伙伴 | 批量硬件、交付计划和售后安排 | 需签订采购或分销协议 |
| 技术支持服务 | 需要联合调试的客户 | 接口联调、问题定位、兼容性测试和开发支持 | 服务范围、周期和费用按项目确认 |
| 定制与联合开发 | 有品牌、结构、软件或行业定制需求的客户 | 需求评估、定制开发、样机验证和项目交付 | 单独立项和签署开发协议 |
| 配件合作 | 需要开发安装件、充电或外设配件的客户 | 接口资料、样品验证和兼容性确认 | 商业销售前确认质量与授权边界 |

## 7. 客户合作流程

1. 获取公开资料：阅读产品规格、协议、SDK、结构文件和开放范围。
2. 提交需求：说明应用场景、硬件数量、开发阶段、软件和结构改动、调试需求及计划时间。
3. 需求确认：K1 团队确认硬件型号、接口能力、支持范围和商务条件。
4. 样机与报价：按需提供开发样机、正式报价单和交付计划。
5. 开发与联调：客户进行 App、系统、配件或结构开发，K1 按约定提供技术支持。
6. 验证与交付：完成兼容性、功能和可靠性验证后进入小批量或批量合作。
7. 正式协议：涉及分销、OEM/ODM、定制开发或制造时，另行签署书面协议。

- 技术支持不包含无限期免费开发、代写客户应用、客户产品认证或制造工艺转移。
- 商业项目中的支持范围、响应时间、验收标准和费用，以报价单或正式合同为准。

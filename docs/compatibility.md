## 3. 兼容规则

- 不同硬件版本的镜像、结构件和刷机参数不得混用。
- 客户端连接后必须读取设备信息、协议版本和能力位。
- 同一主版本内可忽略未知可选字段；未知必需能力必须报错。
- 固件、App、协议和 SDK 必须按 Release 记录组合关系。

## 4. 已验证内容

- 结构 STEP 可由 OpenCascade 重新导入，1 个装配根、31 个结构组件、39 个实体，有效性检查通过。
- Python 协议参考实现有基础帧和消息单元测试。
- 产品规格和硬件设计方案公开版已完成无线芯片信息脱敏。

## 5. 尚未验证

- BSP 干净环境全量编译
- BLE 控制器目标工具链编译、烧录和 OTA
- Android App Debug/Release 构建
- 不同 Android 手机 BLE MTU、重连和音频订阅
- 显示、音频、传感器、触控、射频和功耗联调
- 正式互操作矩阵和长时间稳定性

未完成项目在对应 Release 说明中必须继续标注为“未验证”，不能以硬件可销售或代码可浏览推断为已通过兼容性认证。
